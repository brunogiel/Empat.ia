# User Discovery Workflow

Main workflow for Design with Empathy and AI.

Rules:

- Read only the active step.
- Update `discovery/_engine/state.yaml`.
- Update `discovery/1-desk-research/brief.md`.
- Update the stage document.
- Record assumptions in `discovery/_engine/assumptions.md`.
- Record decisions in `discovery/_engine/decisions.md`.
- Use templates as instructions, not just as empty files.
- If there is contextual fieldwork, update `discovery/4-field/0-observation-plan.md`.
- For each interview, drop raw material into `discovery/4-field/_raw/`, log it in `discovery/4-field/0-index.md`, and copy `discovery/templates/interview-note-template.md`.
- Before synthesizing, extract evidence into `discovery/_engine/evidence.md`.

Every gate ends with a recommendation: Advance, Deepen, Question, or Council.
