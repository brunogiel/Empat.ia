# 2 · Profiling: who you talk to

This folder answers one question: **who do we need to hear from, and how do we reach them?**

What will appear here, one file at a time, when the project gets to this phase:

- `profiles.md`: the people you will interview. Only the interview subject: who they are,
  what makes them the right voice, and who is left out on purpose.
- `recruiting.md`: how you reach them and what you say when you do. This is the only step that
  takes days instead of hours, so it starts early.

An empty folder is not a gap. A file shows up when you enter this phase, already filled with what
the project knows by then. Ask your assistant *"how's it going"* to see where you are.
