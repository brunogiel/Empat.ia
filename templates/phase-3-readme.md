# 3 · The guide: the instrument you take to the field

This folder holds what you carry into the room: **the questions, and how you will work there.**

What will appear here, when the project gets to this phase:

- `guide.md`: the interview questions, and nothing else. Hard cap of 100 lines: if it does not fit,
  the guide is trying to do too much.
- `process.md`: how a session runs, step by step. Consent, recording, what to do when it goes
  off script.

Whoever validates the plan reads this folder before the first interview. An empty folder is not a
gap: the files are written when you enter the phase.
