# Notes

The drawer with an owner. Anything you want written down that has no home yet
goes here, and it is better here than pushed into a file that owns something
else. That is how a field guide ends up swallowing four other documents.

The `editor` empties this at every gate: it moves each item to the file that
owns it and tells you what it moved.

**If something belongs to a phase that has not started yet**, it stays here
under a heading with that phase's name, and moves when the phase begins. The
editor never creates a file to receive it.
