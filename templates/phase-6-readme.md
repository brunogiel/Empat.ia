# 6 · Ideation: from the questions to a few concepts

This folder is born when the project reaches ideation, which some projects do themselves and some
hand to someone else (a design team, an agency).

What lives here:

- `concepts.md`: from the How Might We questions to three to five concepts, minimal. Whatever the
  next phase needs to put in front of people.

If another team does this phase, they can leave their material here (architecture, wireframes)
so the research can read it.
