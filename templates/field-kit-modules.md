# Field Kit Modules

Per-profile variants of the base interview guide.

## Rules

- A module is a delta against `guide.md`, never a full guide duplicated.
- Any block number a module references must exist today in `guide.md`.
- Keep it short: what's replaced, added or skipped, nothing else.

## Base guide blocks

1. Start, rapport and consent
2. Context and day-to-day
3. Current journey
4. Concrete experiences
5. Decisions, motivations and incentives
6. Workarounds and current alternatives
7. Ideal scenario and aspirations
8. Closing
