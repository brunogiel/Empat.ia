# 4 · The field: interviews and observation

This folder holds what the field leaves behind, **one note per person and one per outing.**

What lives here:

- `INT-00X-<name>.md`: one interview. What they said, in their words, with the evidence it feeds.
- `OBS-00X-<place>.md`: one observation, if the plan includes any.
- `0-index.md`: the list of all of them, to see coverage at a glance.
- `_prep/`: the one-page sheet you carry into each interview. Disposable.
- `_raw/`: transcripts, audio, photos and signed consents. **This is personal data.** Check who
  has access to this folder before you put anything in it.
- `feedback/`: your own feedback on how each interview went, one file per interview.

Patterns across interviews do not go here: they live in `5-debrief/`. An empty folder is not a gap:
it fills as the interviews happen.
