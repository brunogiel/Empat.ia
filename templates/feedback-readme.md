# How the interviews are going

Your own feedback, one file per interview, in this folder:
`INT-00X-<name>-<surname>-feedback.md`. It accumulates across files on purpose:
a single number tells you nothing, but the series between interview 1 and
interview 8 tells you whether you are getting better. Every file shares the
same **Measured** table, so you can put two side by side and compare them.

This is about **you**, not about what the interviewee said. What they said
lives in `4-field/INT-00X-<name>-<surname>.md`. Cross-interview patterns live
in `5-debrief/findings.md`. No insights here.

Two things are kept apart in every file, and the labels are not decoration:

- **Measured** comes from counting the transcript. Run it twice, get the same
  number. If a criterion could not be counted, it says so instead of guessing.
- **Read** is judgement. It can be wrong, and you can argue with it.

Coverage of the guide is **reported, never scored**. Abandoning the guide to
follow a good thread is often the right call.

> If someone else ran the interview, technique feedback naming them does not go
> in writing here. Say it in the conversation; write it only if that person, or
> the one who owns the file, says it can go in writing.
